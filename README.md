## 🔍 Lupa — SaaS que construí e opero em produção

Plataforma B2B2C de monitoramento de mídia ([lupanews.app.br](https://lupanews.app.br)), rodando hoje com:

- **90 mil** notícias processadas · **21 mil** clippings entregues · **23** veículos ativos no scraper
- Django 5.1 + Django Ninja (API REST/JWT) · Celery com 3 filas · PostgreSQL 16 + PgBouncer · Redis
- Microsserviço de scraping (FastAPI + Playwright) com buffer local de resiliência e anti-detecção
- Infra distribuída em VMs Oracle Cloud ARM64 via Tailscale — custo **R$ 0/mês**

O código é privado (é um produto), mas as decisões técnicas são públicas:
**➜ [Lupa-Architecture](https://github.com/vhmedeiros/Lupa-Architecture)** — diagramas, trade-offs e o porquê de cada escolha.
