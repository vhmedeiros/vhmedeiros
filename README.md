## 🔍 Lupa — plataforma de monitoramento de mídia em produção

Plataforma de clipping de notícias ([lupanews.app.br](https://lupanews.app.br)), em fase de validação, rodando hoje com:

- **90 mil** notícias processadas · **21 mil** clippings entregues · **23** veículos ativos no scraper
- Django 5.1 + Django Ninja (API REST/JWT) · Celery com 3 filas · PostgreSQL 16 + PgBouncer · Redis
- Microsserviço de scraping (FastAPI + Playwright) com buffer local de resiliência
- Infra em VMs Oracle Cloud ARM64 via Tailscale — custo R$ 0/mês

O código é privado, mas as decisões técnicas são públicas: ➜ [Lupa-Architecture](https://github.com/vhmedeiros/Lupa-Architecture)
